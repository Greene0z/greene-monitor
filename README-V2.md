## Atualização
1. Faça um Exportar JSON na versão atual.
2. No GitHub, substitua apenas:
   - `index.html`
   - `style.css`
   - `app.js`
3. MANTENHA o seu `config.js` atual. Não envie o config.js deste ZIP sobre o seu.
4. Commit.
5. Aguarde o GitHub Pages atualizar.
6. Faça Ctrl+Shift+R e entre com sua conta existente.
