# Greene Monitor V1.1 — atualização

## Antes de publicar
Você já executou `migration-v1.1.sql`. Não precisa executá-la novamente.

## Atualizar GitHub sem perder a conexão
1. NÃO substitua seu `config.js` atual pelo `config.js` deste pacote.
2. No repositório GitHub, substitua `index.html`, `style.css` e `app.js` pelos arquivos desta V1.1.
3. Aguarde o GitHub Pages publicar.
4. Faça Ctrl+Shift+R.
5. Entre com a conta existente.

## Novidades
- histórico de diário e sono
- hábitos personalizados e marcação diária
- dashboard de 7 dias
- progresso de leitura
- objetivos e estudos
- análises iniciais
- isolamento multiusuário via RLS

O arquivo config.js incluído é apenas um modelo para instalações novas.
