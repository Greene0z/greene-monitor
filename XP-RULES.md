# Regras de XP — V2.3

O XP de atividade é derivado dos registros reais.

| Ação | XP |
| --- | ---: |
| Check-in diário | 10 |
| Hábito concluído | 8 |
| Leitura | 1 por página, com limite de 80 XP por registro |
| Estudo | 1 XP a cada 5 min, contando até 120 min por sessão |
| Exercício | 1 XP a cada 5 min, contando até 90 min por sessão |
| Entrada no diário | 10 |
| Nota criada | 5 |
| Livro marcado como lido | 100 |
| Objetivo manual concluído | 100 |

Quests e conquistas podem adicionar XP bônus.

## Níveis
A progressão exige progressivamente mais XP:
- Nível 2: 100 XP total
- Nível 3: 300 XP total
- Nível 4: 600 XP total
- Nível 5: 1.000 XP total

A curva continua aumentando de forma gradual.

## Moedas
A cada 100 XP de atividade acumulado, o sistema concede 10 moedas.
Quests e conquistas também concedem moedas.

## Regra importante
XP já conquistado não diminui quando o total derivado dos registros cai. Indicadores pessoais como humor, estresse, foco e qualidade do sono nunca geram penalidades.
